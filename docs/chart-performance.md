# 长历史图表性能（2.8.5）

保留 2.8.4 的平滑曲线、峰谷、重置提示、配色与交互，减少动画中反复计算和绘制的开销。基线为 `d39e921`（2.8.4），测量机为 Windows amd64、AMD Ryzen 7 8845H、Go 1.27.1。

## 改动

曲线、填充和重置提示在后台生成不可变图层。入场动画改变裁剪宽度，页面动画和滚动移动图层，悬停指示点由 GUI 单独绘制。后台使用已有依赖 `golang.org/x/image/vector` 的独立缓冲区，避免跨线程共享 MyGO 纹理图集；没有增加框架、依赖版本或额外进程。

图层准备期间继续绘制当前数据的矢量曲线。每个图表最多有一个构建任务；尺寸、DPI、主题和数据变化时合并请求并丢弃过期结果，完成后通知 GUI。相同几何的快照直接复用图层。切换指标、范围、页面或进入空数据状态会释放旧图层；保留最终像素，不保留另一套 UI 引擎和纹理图集。

当前指标的采样、日期格式化、最大值和分段只在数据或指标改变时计算。悬停由 O(n) 遍历改为 O(log n) 二分查找，保留原来的平局和重复时间选点规则。数据库与统计口径不变，悬停和键盘浏览保留快照中全部记录；额度服务原有的分桶规则继续使用。后台栅格化与矢量路径共用单调切线算法；独立抗锯齿可能产生很小的边缘舍入差异，回归测试约束平均通道差异小于 0.5%。

`charts.go` 从 244 行减少到 205 行，绘制和缓存职责移到独立模块。新增栅格化、生命周期验证和测量工具，整体代码行数增加。

## 图表绘制与移动测试

使用同一份 2,400 点合成序列，额度包含 480 个重置周期。1100 × 260 DIP 窗口、150% DPI，三轮 1 秒测试取中位数；两版使用相同测试代码和预热。移动测试每帧改变位置 0.1 DIP，实际重绘图像。

| 每帧 | 2.8.4 | 2.8.5 | 耗时下降 |
| --- | ---: | ---: | ---: |
| Token，重复绘制 | 1.204 ms | 0.032 ms | 97.3% |
| 额度，重复绘制 | 0.936 ms | 0.035 ms | 96.3% |
| Token，移动 | 16.428 ms | 5.325 ms | 67.6% |
| 额度，移动 | 11.836 ms | 5.575 ms | 52.9% |

| 移动时每帧分配 | 2.8.4 | 2.8.5 | 分配字节下降 |
| --- | ---: | ---: | ---: |
| Token | 256,247 B / 33 次 | 285 B / 20 次 | 99.9% |
| 额度 | 354,994 B / 2,426 次 | 286 B / 20 次 | 99.9% |

该测试包含图表 UI 构建、路径 / 遮罩查找和软件合成，**不等于整个应用的 GPU 帧或屏幕 FPS**。重复绘制时软件渲染器会跳过未变像素，因此同时列出移动测试。缓存生成和首次绘制不计入预热后的数字；首次和持续改变数据时仍需计算曲线，缓存不是免除这些工作。

## 真实原生窗口

新建隔离数据库，包含 100 天、2,400 条小时用量和额度观测、480 个五小时周期，以及基础验收记录。两版都选择“全部历史”，使用正常动画；三轮交错运行五页、窗口控制和逐次列表验收。原生窗口由 GPU 绘制。

| 额度页绘制阶段 | 2.8.4 | 2.8.5 |
| --- | ---: | ---: |
| 中位数 | 1.0 ms | 0.5 ms |
| P95 | 2.0 ms | 1.6 ms |
| 最大值 | 3.7 ms | 3.7 ms |
| 帧样本 | 156 | 162 |

整个原生额度页帧的中位数均为 16.1 ms、P95 均为 16.9 ms；引擎帧计时包含呈现等待，收益主要是释放绘制预算，不能据此宣称屏幕 FPS 翻倍。总览的绘制 P95 从 1.6 ms 降到 0.6 ms，但首次重建仍可能出现较慢帧。日志以 0.1 ms 精度记录，低于精度的值不作为零耗时。

三次完整原生验收的进程峰值中位数：私有内存 270,004,224 → 266,952,704 B，工作集 244,043,776 → 237,363,200 B。该峰值包含最大化、截图和全部页面，**不是稳态内存**；每帧分配下降也不等于常驻内存下降 99.9%。基准尺寸的一张曲线图层为 1,495,908 B，约 1.43 MiB；只保留当前图层，后台工作区完成后回收，GUI 原有 GC / 软预算设置继续使用。

完整原始基准和统计口径见 [测量数据](chart-performance-results.json)。

Windows 安装包为 7,904,216 B（约 7.54 MiB），比 2.8.4 增加 20,742 B、约 0.26%；主程序为 21,228,032 B，签名更新归档为 9,607,044 B。新增缓存与独立栅格化代码带来小幅体积增加，安装包仍只包含原生程序和图标。

曲线范围、采样误差、悬停 / 键盘、断点 / 填充、缓存失效、快速变化时的过期任务、空数据和旧缓存释放验证均通过。完整 Go 测试、原生五页 / Win32 小窗口 / 窗口控制、并发检查、浅色 / 深色 / 高 DPI 和安装验收使用隔离数据。

基线工作树只加入相同的基准文件，以及 `MONITOR_CHART_PROFILE=1` 下设置“全部历史”和输出阶段标记的验收钩子；生产算法使用 2.8.4 原实现。统计脚本验证两份基准文件的 SHA-256 相同。原生帧脚本要求两版均有相同验收钩子，其余用户运行不启用该环境变量。
