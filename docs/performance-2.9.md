# 2.9 性能与体积

测量环境：Linux x64（2 vCPU，Intel Xeon 2.9 GHz），Go 1.27.1。基线为 2.8.5（`main`，MyGO 0.2.15），使用相同的基准代码和合成数据。数值为单次运行结果，用于对比，不代表 Windows 实机帧率。

## 统计快照

`go test ./internal/monitor/ -run XXX -bench Snapshot -benchmem`，20,000 条用量记录、100 个会话、全部时间范围。

| 页面 | 2.8.5 | 2.9.0 | 耗时 | 分配次数 |
| --- | --- | --- | --- | --- |
| 总览 | 114 ms · 762k 次 | 65 ms · 243k 次 | −43% | −68% |
| 历史分析 | 86 ms · 482k 次 | 59 ms · 242k 次 | −31% | −50% |
| 活动 | 87 ms · 382k 次 | 58 ms · 243k 次 | −33% | −36% |
| 设置 | 12.8 ms · 2.0k 次 | 0.6 ms · 2.0k 次 | −95% | 持平 |

- 模型筛选列表原来用 `SELECT DISTINCT model` 读取全部用量行。现在新增 `usage(model,account)` 索引，用递归 CTE 做松散索引扫描，每个模型只需一次索引查找。
- 数据覆盖范围的最早 / 最晚时间改用独立子查询，可以走时间索引。
- 排行、合计和活动日历改为在普通结构体字段上累加，最后才生成结果对象，去掉了每行十余次 map 写入和浮点装箱。
- 记录已按时间排序，同一 UTC 分钟内的行复用上一行的时间桶，不再逐行解析时间和格式化。

## 界面帧

`go test ./internal/nativeapp/ -run XXX -bench 'BenchmarkViewFrame$' -benchmem`：1280×860 DIP，入场动画结束后，每帧包括构建、布局和软件绘制。

| 页面 | 2.8.5 | 2.9.0 |
| --- | --- | --- |
| 总览 | 1.06 ms · 2,272 次分配 | 0.58 ms · 347 次分配 |
| 活动 | 0.96 ms · 2,207 次分配 | 0.54 ms · 178 次分配 |
| 历史分析 | 0.66 ms · 511 次分配 | 0.90 ms · 541 次分配 |
| 额度 | 0.24 ms · 150 次分配 | 0.28 ms · 170 次分配 |
| 设置 | 0.16 ms · 87 次分配 | 0.30 ms · 102 次分配 |

总览和活动页去掉了整窗背景位图和逐格的日历元素，热力图改为单个绘制元素，日期与格子的换算和命中检测都是 O(1)。历史分析、额度和设置页的单帧略慢，原因是新界面显示的内容更多：历史分析顶部增加了指标卡片，设置页改为分组列表。各页单帧都在 1 ms 以内。

翻译函数 `tr` 改为一次扫描替换 `{0}`、`{1}` 等占位符，不再为每个参数调用 `fmt.Sprintf` 和 `strings.ReplaceAll`。

## 安装包体积

| | 2.8.5 | 2.9.0 |
| --- | --- | --- |
| `Codex Monitor Native.exe` | 21,227,520 B | 21,679,104 B（+2.1%） |
| 安装包（NSIS / LZMA） | 7,906,934 B | 7,204,172 B（−8.9%） |

- 品牌图从 1254 px（1.2 MB）缩小为 160 px（27 KB）。它最大只显示为 40 DIP，160 px 已足够 400% 缩放使用；原来的按 DPI 裁剪 mip 层代码也随之删除。
- 发布构建加上 `-tags mygo_noinspector`，去掉开发用的界面检查器（约 240 KB）。
- 可执行文件比 2.8.5 略大，原因是 MyGO 从 0.2.15 升级到 0.5.2。
- LZMA 字典从 16 MB 改为 32 MB 后，安装包只多出 75 B，因此保持 16 MB。

## Windows x64 收尾验收

Go 1.27.1、Node 22.22.0、MyGO 0.5.2；本机显示缩放为 150%。使用 `internal/testfixture` / `cmd/fixture` 合成数据，不读取个人监测数据。

| 发布文件 | Windows 实测 |
| --- | --- |
| `Codex Monitor Native.exe` | 21,695,488 B |
| NSIS 安装包 | 7,205,774 B |
| 签名更新归档 | 9,091,514 B |

Windows 安装包比 Linux 交叉编译结果 7,204,172 B 增加 1,602 B（约 0.02%）。本轮还补充了透明度回退、自动更新设置和原生外观验收代码，不能将差异单独归因于构建平台。

- `go test ./...`、`go vet ./...`、`go tool mygo vet .`、`npm run build`、合成数据 `npm start`、`npm run native:check`、`npm run package` 和 `npm run package:check` 通过。
- 原生验收覆盖五页、逐次调用、窗口移动 / 缩放 / 最小化 / 最大化 / 关闭至托盘、560×380 DIP 小组件及浅深色设置四个分组。
- 内存绘制验收覆盖 100%、150%、200% 缩放、浅深色、减少动态效果及最小窗口宽度，确认工具栏按钮避让原生标题栏按钮；透明度偏好测试验证侧栏回退为完全不透明。
- 使用同一 MyGO SDK 的隔离探针模拟 2.8.5 → 2.9.0 更新：拒绝篡改归档且不替换可执行文件；接受正确签名归档，安装后的主程序 / 图标哈希匹配发布包，并保留用户附加文件。
- 已检查原生页面及浅深色设置截图，未发现控件重叠或缩放错位。100% / 200% 为内存绘制结果，未切换系统 DPI。
- 桌面控制工具本机连接不可用：系统透明 / 动效 / 主题开关的实时切换、鼠标拖动 / 双击及标题栏按钮的直接点击、Ctrl+R / Ctrl+E 的实际输入和保存对话框仍需手工复核；不能把程序接口验收视为这些手工步骤已经完成。

验收报告与截图位于 Git 忽略的 `artifacts/native-acceptance/`，安装和更新测试报告位于 `artifacts/`。
